#Арканоид - тестовое задание

Классическая игра Arkanoid на HTML5, CSS3, JavaScript и PixiJS. Управление мышью, система очков, режим обучения, звуки и анимации

#Технологии

HTML5, CSS3, JavaScript, PixiJS

#Как запустить

Через терминал нужно ввести команду:

npx serve
 
 И далее перейти по ссылке

 #Управление

 Мышь - движение ракетки

 Пробел / клик - старт и рестарт 

 M - ВКЛ / ВЫКЛ

 #Время выполнения

 Изучение документации, продумывание логики и внешнего вида игры, поиск музыки - около 5 часов

 Сама реализация - около 7 часов

 Итого: около 12 часов
